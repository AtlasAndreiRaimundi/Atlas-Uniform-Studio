## Como usar
- Modalidade escolhida por Andrei: licença de uso com implantação e manutenção, preservando a propriedade do sistema com Andrei. Não há cessão patrimonial nesta proposta. Primeiro resolver titularidade e condições comerciais.
- Licença permite uso dentro do escopo contratado. Marca, dados, hospedagem, contas e suporte são objetos distintos. A intenção de preservar a propriedade precisa constar de instrumento bilateral válido.
- Copiar as minutas para ambiente restrito, preencher todos os campos [PREENCHER], resolver as alternativas e remover as instruções editoriais somente da versão final.
- Advogado das partes deve revisar especialmente vínculo de emprego, cadeia de direitos, limitações de responsabilidade, tributos, privacidade e assinatura. Este pacote é preparatório, não parecer jurídico.
- Assinar a versão final com anexos identificados; guardar o original e a trilha de assinatura fora do repositório público.
- Somente executar a troca de marca após o gatilho contratual, autorização da marca e aceite técnico.
